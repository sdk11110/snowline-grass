# 复用、恢复与改造记录

本项目基于 Hemu Ski 当前公开网页版本进行研究与改造：
https://eric1hua.github.io/hemu-ski/

用户明确选择保留人物、地形和现有玩法逻辑，在此基础上拆分并个性化定制。

## 代码来源

没有取得作者当前完整开发仓库。`src/recovered/` 是从发布模块恢复、重命名、按职责拆分并修改的可编辑代码，
不声称是作者原始文件、原始变量名或本项目从零原创的全部逻辑。

原发布包中的职责被拆成物理、输入、人物、动作、装备、镜头、天气、地形、森林、建筑、索道、温泉、载具、动物、
音频、地图导航、场景交互、运行会话与渲染循环等模块。每个模块头部保留对应原发布URL；
`src/recovered/recovery-manifest.json` 记录来源、迁移的符号以及共享读写依赖。

`shared-runtime.js` 和 `main.js` 仍承担初始化与跨系统组装。原单字母符号未能全部可靠推回原名称，
部分内部变量仍保留短名；本次恢复了具名系统边界和关键物理/天气参数，未宣称逐行还原原作者源码。

## 第三方基础库

`src/vendor/three/` 保留与原版一致的Three.js r186渲染、核心、GLTF与骨骼处理代码，并与游戏玩法分开。
本轮没有把它替换成另一版本，以免改变现有材质与渲染行为。Three.js采用MIT许可；原文件已有声明随代码保留。

## 数据和素材

`public/` 只存静态资源，不含原站编译JS、CSS或HTML。59个文件及逐文件来源与哈希见根目录 `ASSET_PROVENANCE.json`。
人物、树木、建筑、载具、动作、内嵌纹理、字体、声音与地形数据仍保留来源归属。地图数据中的地形与OpenStreetMap声明未移除。

## 本轮新增与修改

- 新增独立Vite工程、开发/构建入口与source maps，正常构建不依赖原镜像项目或在线原站。
- 恢复可编辑模块路径，拆开第三方库与玩法，去掉旧构建器的预加载包装并交由本工程构建器处理。
- 通过显式共享上下文保留跨模块读写及原初始化顺序，避免改变既有玩法流程。
- 给真实滑手物理求解接入重力、阻力、转向和速度上限；默认倍率1保持原手感。
- 给人物、雪具、镜头与声音设置补统一控制入口。
- 新增实时定制面板、玩法预设、项目名称/强调色、浏览器本地保存和JSON导入导出。
- 新增接口行为测试、真实物理对照测试、源码结构检查与资源校验。

`src/studio.js`、`src/customize/`、项目构建配置与检查工具是本次新增的改造层。
临时恢复脚本、AST工具、分析目录及缓存已在交付前清理。最终源码可直接修改和构建，
不需要重新下载原版或再执行恢复过程。物理对照测试仅保留一份必要的原求解器基线。

## 保留的边界

源码拆分和素材复用不会改变原资源的作者归属。原站没有取得完整根许可证或单项素材授权清单；
本次仅在本机制作可定制研究工程，没有发布或重新授予原资源许可。
